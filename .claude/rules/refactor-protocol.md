# Refactor & Cleanup Protocol

## ก่อนเริ่ม
1. เปิด Plan Mode
2. สำรวจโครงสร้างทั้งโปรเจกต์ + หา dead code ด้วยการเช็คการเรียกใช้จริง
3. สรุปรายการที่จะลบ/ย้าย/แก้ ให้ user ดูก่อน — ยังไม่แก้ไฟล์จริง
4. แตกเป็น subtask เล็กๆ ต่อ module ห้ามทำรวดเดียวทั้งโปรเจกต์

## กฎการลบ/ย้าย
- โค้ดที่ user บอกให้ "เก็บไว้ก่อน" → ห้ามลบ ย้ายไป /archive/<module>/ พร้อมคอมเมนต์เหตุผล+วันที่
- โค้ดอื่นที่ไม่ได้ใช้และไม่มีใครขอเก็บ → ลบได้เลย (git เก็บ history ให้อยู่แล้ว)
- ไฟล์ความจำ/state เก่า → เคลียร์ entry ที่ไม่เกี่ยวแล้ว รวม log ซ้ำซ้อน

## ระหว่างทำแต่ละ subtask
1. รอ user ยืนยันรายการจากขั้นสำรวจก่อน
2. แก้ทีละ module
3. รัน test (hook บังคับอยู่แล้ว)
4. Commit ทันทีที่จบแต่ละ subtask พร้อม message ชัดเจน

## จบแต่ละ subtask
อัปเดต HANDOFF.md: ลบอะไร, ย้ายอะไรไปไหนทำไม, อะไรยัง verify ไม่ครบ

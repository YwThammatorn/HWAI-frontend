HWAI Agent - Mock Data Seed Commands
=====================================

วิธีใช้:
1. รัน npm run dev แล้วเปิด http://localhost:3000
2. กด F12 เปิด DevTools -> แท็บ Console
3. Copy คำสั่งด้านล่าง (ทำ Curriculum ก่อน Courses จะได้ลิงก์ตรงกัน) วางแล้ว Enter
4. หน้าจะ reload อัตโนมัติ

---

[1] Curriculum + รายวิชาในหลักสูตร (9 หลักสูตร, 51 วิชา)

fetch('/mock-data/curriculum-mockup.json').then(r=>r.json()).then(d=>{localStorage.setItem('hwai_curriculum_versions_v1', JSON.stringify(d.curriculumVersions)); localStorage.setItem('hwai_course_templates_v1', JSON.stringify(d.courseTemplates)); location.reload();});

---

[2] รายวิชาที่เปิดสอน (6 วิชา, ลิงก์กับหลักสูตรด้านบน)

fetch('/mock-data/courses-mockup.json').then(r=>r.json()).then(d=>{localStorage.setItem('hwai_courses_v2', JSON.stringify(d)); location.reload();});

---

[3] อาจารย์ พร้อม assign เข้าวิชาแล้ว (5 คน — ต้องทำ [2] ก่อน จะได้ courseId ตรงกัน)
    สมศักดิ์ เจริญสุข -> 2 วิชา, ประเสริฐ ดีเลิศ -> 1 วิชา, กานต์ ศรีสุวรรณ -> 2 วิชา,
    นภาพร มานะ (TA) -> share วิชากับสมศักดิ์, วิทยา สมบูรณ์ (TA) -> ยังไม่ assign (ทดสอบ empty state)

fetch('/mock-data/teachers-mockup.json').then(r=>r.json()).then(d=>{localStorage.setItem('hwai_managed_teachers_v1', JSON.stringify(d)); location.reload();});

---

[3b] นักศึกษา - ไม่ต้องใช้ console

ไปที่ /admin/users -> กด "นำเข้า CSV" -> เลือกไฟล์:
  - test-data/students_sample.csv   (นักศึกษา, 30 แถว — 25 ใช้ได้ปกติ + 5 แถวตั้งใจใส่ผิดไว้โชว์ validation ของหน้านี้)

    ID ใช้ scheme เดียวกับ cohort ใน [5] (690701xx=CE69, 680201xx=CE68, 670101xx=CE67, 700101xx=CE70)
    ต่อเลขให้ไม่ชนกัน ยกเว้นแถวสุดท้ายที่ตั้งใจให้ชนตรงๆ — ทำ [5] ก่อนถึงจะเห็นผลข้อ 5 ด้านล่างชัด:
    1. studentId ว่างช่อง program (69070119)   -> "ขาด: program"
    2. studentId สั้นแค่ 6 หลัก (690701)         -> "รหัสนักศึกษาต้องเป็นตัวเลข 8 หลัก"
    3. อีเมลรูปแบบผิด "not-an-email" (69070120)  -> "อีเมลไม่ถูกต้อง"
    4. อีเมลไม่ตรงกับ studentId (68020111)        -> "อีเมลต้องเป็น รหัสนักศึกษา@kmitl.ac.th"
    5. studentId ซ้ำกับคนที่มีอยู่แล้ว (69070101, ต้องทำ [5] ก่อน) -> แถวนี้จะไม่ error ในตาราง preview
       (แอปยังไม่ tag ว่า error ตรงนี้) แต่จะไม่ถูกนับใน "ใหม่ N" และไม่ถูก import จริง — เป็นพฤติกรรมเดิมของแอป

(อาจารย์ใช้ [3] ด้านบนแทน CSV import เพราะต้องผูก courseId ด้วย ถ้าอยากได้อาจารย์เปล่าๆ ไม่ผูกวิชา ค่อยใช้ CSV import teachers_sample.csv แทน)

[5] นักศึกษาครบ flow — cohort + ลงทะเบียนวิชา + งาน + rubric + ผลตรวจ
    (ต้องทำ [2] ก่อน เพราะลงทะเบียนเข้า c-mock-1 "การเขียนโปรแกรมคอมพิวเตอร์" ของสมศักดิ์)
    15 คนใน cohort (CE67/68/69/70, 1 คน inactive) — 3 คนแรก (69070101-103) ลงทะเบียนวิชา c-mock-1 จริง
    อีก 11 คนที่เหลือ (69070104-108, 68020101-104, 67010101, 70010101-102) ยังไม่ลงวิชาไหนเลย
    — ไว้ใช้ทดสอบการ import นักศึกษาเข้าวิชา ดู [7] ด้านล่าง
    วิชานี้มี 2 งาน: [1] ครบกำหนดแล้ว มี rubric + ผลตรวจ 3 แบบ (ตรวจแล้ว/รอตรวจ/ยังไม่ตรวจ)
                     [2] ยังไม่ถึงกำหนด ยังไม่มีใครส่ง
    ล็อกอินเป็นนักศึกษาด้วยอีเมล 69070101@kmitl.ac.th (รหัสผ่านอะไรก็ได้ 4 ตัวขึ้นไป) จะเห็นวิชา+งานนี้

fetch('/mock-data/student-flow-mockup.json').then(r=>r.json()).then(d=>{localStorage.setItem('hwai_cohort_students_v1', JSON.stringify(d.cohortStudents)); localStorage.setItem('hwai_students_v1', JSON.stringify(d.courseStudents)); localStorage.setItem('hwai_assignments_v1', JSON.stringify(d.assignments)); localStorage.setItem('hwai_rubrics_v1', JSON.stringify(d.rubrics)); localStorage.setItem('hwai_submissions_v1', JSON.stringify(d.submissions)); location.reload();});

[6] รีเซ็ตแค่ "ผลตรวจ" กลับไปที่ค่าเริ่มต้น (เผื่อทดสอบส่งงานซ้ำๆ)
    ใช้ตอนทดสอบ role student แล้วกดส่งงาน "โปรเจกต์เล็ก: เครื่องคิดเลข" (a-mock-2) ไปแล้ว
    อยากให้กลับไปเป็น "ยังไม่ส่ง" เพื่อลองกดส่งใหม่อีกรอบ — ไม่กระทบ cohort/รายวิชา/งาน/rubric เลย
    แก้แค่ hwai_submissions_v1 กลับไปเป็น 3 รายการเดิมของ a-mock-1 (ตรวจแล้ว/รอตรวจ/ยังไม่ตรวจ)
    ส่วน a-mock-2 จะไม่มี submission อยู่เลย เหมือนตอนเริ่มต้น

fetch('/mock-data/student-flow-mockup.json').then(r=>r.json()).then(d=>{localStorage.setItem('hwai_submissions_v1', JSON.stringify(d.submissions)); location.reload();});

[7] ทดสอบนำเข้านักศึกษาเข้าวิชา (teacher CSV import + cross-check กับระบบ)
    ต้องทำ [5] ก่อน (ให้มี cohort 15 คนใน hwai_cohort_students_v1)
    ไปที่ /teacher/courses/c-mock-1/students/import -> อัปโหลด test-data/course-import-test.csv

    ไฟล์นี้มี 12 แถว ตั้งใจใส่ชื่อ/อีเมลผิดในทุกแถวที่ยังไม่ลงวิชา เพื่อพิสูจน์ว่าระบบดึงชื่อจริงจากระบบมาแทน:
    - 10 แถวแรก (69070104-108, 68020102-104, 70010101-102) -> อยู่ใน cohort แล้ว ยังไม่ลงวิชาไหน
      -> ควร "พร้อม import" ทั้งหมด และตอน preview ชื่อ/อีเมลจะเปลี่ยนเป็นของจริงจากระบบ ไม่ใช่ที่พิมพ์ในไฟล์
    - แถว 69070101 -> ลงทะเบียน c-mock-1 อยู่แล้ว -> ต้องขึ้น "ลงทะเบียนแล้ว" แล้วถูกข้าม
    - แถว 99999999 -> ไม่มีใน cohort เลย -> ต้องขึ้น "ไม่พบในระบบ" แล้วถูกข้าม

หมายเหตุ:
- ไฟล์ json ต้นทางอยู่ใน public/mock-data/ (courses-mockup.json, curriculum-mockup.json, teachers-mockup.json, student-flow-mockup.json)
  ถ้าแก้ข้อมูล mock ให้แก้ที่ test-data/*.json ก่อน แล้ว copy ทับไฟล์ใน public/mock-data/ ด้วย
- คำสั่งพวกนี้ทำงานเฉพาะตอน dev server รันอยู่ (npm run dev) เพราะ fetch ไปที่ localhost
- teachers-mockup.json ใช้ courseId ที่ตรงกับ courses-mockup.json (c-mock-1..6) ทำ [2] ก่อน [3] เสมอ
- student-flow-mockup.json ก็ใช้ courseId c-mock-1 เหมือนกัน ทำ [2] ก่อน [5] เสมอ
- students_sample.csv ([3b]) กับ course-import-test.csv ([7]) เป็นคนละไฟล์ คนละหน้า แต่ ID ใช้ scheme เดียวกัน:
  — [3b] คือ import นักศึกษาเข้า cohort กลางของระบบ (ผ่าน /admin/users, format 6 คอลัมน์ studentId,firstName,lastName,email,cohort,program)
  — [7] คือ import นักศึกษาที่มีอยู่ใน cohort แล้ว เข้าไปลงทะเบียนวิชาใดวิชาหนึ่ง (ผ่านหน้า course ของอาจารย์, format 4 คอลัมน์ student_id,first_name,last_name,email)
  — ทำ [3b] เสร็จแล้ว คนที่เพิ่งนำเข้ามา (เช่น 69070109-118) ก็เอาไปใส่ใน CSV แบบ [7] เพื่อทดสอบ import เข้าวิชาต่อได้เลย

HWAI Agent - Mock Data Seed Commands
=====================================

วิธีใช้:
1. รัน npm run dev แล้วเปิด http://localhost:3000
2. กด F12 เปิด DevTools -> แท็บ Console
3. Copy คำสั่งด้านล่าง (ทำ Curriculum ก่อน Courses จะได้ลิงก์ตรงกัน) วางแล้ว Enter
4. หน้าจะ reload อัตโนมัติ
